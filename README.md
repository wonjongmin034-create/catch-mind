# 그림 퀴즈 🎨

학생 개별 태블릿으로 하는 모둠별 그림 맞히기 게임 (캐치마인드 방식).

- 이름 + 반 입력 → 모둠 번호(1~8) 눌러 입장. 같은 반·같은 모둠끼리 한 방.
- 먼저 들어온 학생이 방장(👑): 라운드 수·그리는 시간 정하고 시작. 방장이 나가면 다음 학생이 자동으로 이어받음.
- 차례가 오면 단어 3개 중 하나 골라 그리기. 나머지는 채팅으로 정답 입력.
- 난이도(방장이 선택): 쉬움 / 🔥어려움(기본) / 섞어서. 어려움 = 말장난(검정색 = 검+정색)·감정·개념·속담·관용구.
- 점수: 맞힌 순서대로 10·8·7·6·5점, 그린 사람은 누가 맞힐 때마다 +3점. 어려운 단어는 1.5배(그린 사람 +5).
- 시간이 절반·3/4 지나면 글자 힌트 공개. 거의 맞히면 "아깝다!" 알림.
- 새로고침해도 같은 모둠으로 다시 들어가고 점수·그림 유지.

## 기술

React + Vite + TypeScript. 서버 없이 Supabase Realtime(broadcast + presence)만 사용 — DB 테이블 없음.
도토리 마을과 같은 Supabase 프로젝트 (`src/net.ts`).

- `src/useRoom.ts` — 방 연결, 방장 진행 로직(차례·타이머·채점·힌트), 채팅
- `src/Board.tsx` / `src/boardModel.ts` — 그림판 (좌표 1000×750 정규화, 0.25초마다 묶어서 전송, 받는 쪽은 부드럽게 이어 그림)
- `src/words.ts` — 제시어 (카테고리별)

무료 플랜 한도: 초당 메시지 100개(1분 평균, 보내기+받기 모두). 5모둠 × 5명이 동시에 그려도 대략 한도 안.

```bash
npm install
npm run dev
```
